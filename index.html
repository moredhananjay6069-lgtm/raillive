Live data settings

The page ships with a demo feed (representative sample data). To use real live status, paste a RapidAPI key for an Indian Railways live-status API below. It is stored only in this browser (localStorage) and is never written into the page source.

Calls are made directly from your browser to the API host (RapidAPI endpoints send CORS headers). If a request fails, the page falls back to the demo feed automatically.

About. रेललाइव / RailLive is a single-file static web app for Indian Railways live train location. By default it renders a demo feed of representative timetables — positions and delays are illustrative, not official. Add a live-status API key in Live data settings to pull real running status; the page then calls the provider directly from your browser. Always cross-check against the official NTES / enquiry.indianrail.gov.in before travel.
